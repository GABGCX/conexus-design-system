# Lista numerada

Lista de itens sequenciais em que o número, e não um marcador, carrega a ordem. Usada para etapas, serviços ou argumentos numerados.

O consumidor fornece um número (texto livre, como "01" ou "02") e um título curto por item; uma régua de 1px separa os itens.

Quando usar: para descrever etapas de um processo, um repertório de serviços ou qualquer sequência em que a ordem importa. Para uma lista sem ordem, use o Marcador de lista.

Faça: escreva o número em `numero-lista`, Sora 300; escreva o título em `texto-forte`, Sora 600; separe os itens com `divisoria` (1px, cor `regua`).

Não faça: não coloque o número na mesma cor do título. O contraste entre os dois pesos de Sora (300 e 600) é o que dá hierarquia à lista. Não use esta lista para conteúdo sem ordem relevante.
