# Bloco de citação

Bloco de fundo claro com um filete teal de 3px no topo, usado para propósito, promessa ou depoimento em destaque.

O consumidor fornece uma frase curta (uma citação ou afirmação de posicionamento); o bloco não tem autor nem foto por padrão.

Quando usar: para uma frase de propósito, uma promessa de valor ou um depoimento. Sempre uma única frase de impacto, nunca um parágrafo longo.

Faça: use o fundo `fundo-citacao` (#F3F7F8, tom próprio deste bloco); aplique o filete de 3px em `teal-conexus` apenas no topo; escreva a frase no estilo `subtitle` ou próximo dele, cor `navy`.

Não faça: não adicione sombra ou borda ao redor do bloco além do filete superior; não use mais de um Bloco de citação na mesma página.
