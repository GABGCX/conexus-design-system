# Régua de abertura

Barra de 52 × 3px que abre toda capa e página de fechamento, sempre posicionada acima do kicker.

O consumidor fornece apenas o fundo da peça (branco/claro ou navy); a régua não recebe texto nem conteúdo.

Quando usar: no topo de uma capa, ou logo acima do par kicker + título que abre uma página de fechamento. Nunca no meio do conteúdo: para isso, use a `divisoria` de 1px.

Faça: use `teal-conexus` quando o fundo é branco ou `fundo`; troque para `teal-claro` quando o fundo é `navy` (regra de detalhe sobre navy). Mantenha a largura fixa de 52px e a altura de 3px.

Não faça: não estique a régua para acompanhar a largura da coluna; não a use em fundo colorido diferente de branco, `fundo` ou `navy`; não a duplique na mesma página.
